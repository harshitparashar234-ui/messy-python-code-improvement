# Messy Python Code Improvement

## Overview
This project demonstrates how messy Python code can be improved with AI assistance.

## Files
- `messy_code.py` - Original code with short variable names and inconsistent formatting.
- `improved_code.py` - Refactored code with meaningful names, functions, docstrings, and improved readability.

## Improvements Made
- Replaced unclear variable names with meaningful names.
- Added consistent indentation and formatting.
- Divided the program into reusable functions.
- Added docstrings to explain each function.
- Used direct iteration instead of indexing through a list.

## Technologies Used
- Python 3
- AI-assisted code improvement

## How to Run
Run either file using Python 3:

```bash
python messy_code.py
python improved_code.py
```
